# Vyvræl 0.1.0-alpha.1

*A dragon-flavoured UCI chess engine in Rust, built with AI and playing for
the attack.*

The first release. Vyvræl is a complete chess engine that speaks UCI: it
plays legal chess in a GUI or a match tool, keeps to its clock and survives
bad input. It is an **alpha**: early, slow for the depth it reaches, and of
unknown strength.

## Read this first

- **Strength is unmeasured.** No rating is claimed. The evaluation's values
  are reasoned, not tuned, and have never been measured in play (known issue
  KI-8). Measuring the engine against a ladder of other engines is the next
  milestone. "Playing for the attack" is a style goal, not a claim about
  strength.
- **`UCI_Elo` is not calibrated.** `UCI_LimitStrength` and `UCI_Elo` work and
  their settings are ordered (a higher number plays better), but the number
  is a label, not a measured rating.
- **A casual-only Lichess bot is planned**, on the account `Vyvrael-Chess`,
  run by the maintainer. Rated games wait until strength is measured and the
  search heuristics are tested (after 0.2.0). See
  [LICHESS.md](../LICHESS.md).
- **Built under the 0rwx X scale.** The code is written by AI coding agents
  and curated by the maintainer, who does not read every line. Trust rests
  on the tests, the documentation and a history of small commits. See
  <https://0rwx.com/> and the README.

## What is in it

- **Board and move generation:** bitboards with magic-bitboard sliders, FEN
  in and out, Zobrist hashing, legal move generation checked by perft
  against the published node counts of six reference positions.
- **Evaluation:** hand-crafted, material plus tapered piece-square tables,
  behind an interface a neural network can replace later.
- **Search:** negamax with alpha-beta, iterative deepening, quiescence
  search, mate scores, draws by repetition, the fifty-move rule and bare
  material. No transposition table and no move ordering in the main search
  yet.
- **UCI:** `uci`, `isready`, `ucinewgame`, `position`, `go` (clocks,
  `movetime`, `depth`, `nodes`, `infinite`), `stop`, `setoption`, `quit`,
  with the search on its own thread. Seven options: `Hash`, `Threads`,
  `DeterministicRNG`, `RngSeed`, `UCI_LimitStrength`, `UCI_Elo` and
  `Move Overhead`. Every command and option is in [UCI.md](../UCI.md).
- **Command line:** `perft`, `eval` and `search` subcommands for testing.

## Known limitations

From the "Known issues" table in [ROADMAP.md](../ROADMAP.md):

- **KI-8:** the evaluation's strength is unmeasured.
- **KI-9:** the search is slow without move ordering; it plays shallowly for
  the time it uses.
- **KI-10:** the first search depth cannot be interrupted, and in positions
  with very many captures it can overrun a short time budget.
- **KI-2:** FEN parsing is strict and has no repair mode for sloppy input.

Also: `Hash` is accepted but has no effect yet, `Threads` can only be 1, and
there is no pondering, `searchmoves` or `go mate`.

## How it was checked

- 417 unit tests and five integration suites (perft, UCI over real pipes,
  pinned search results, a consistency walk of the move tree, whole games),
  all passing, with `cargo fmt` and `cargo clippy -D warnings` clean.
- 60 complete games in `cutechess-cli` 1.5.1 at 10+0.1 on the maintainer's
  Windows workstation: 20 of self-play and 40 against five weak engines.
  None ended by an illegal move, a crash, a stall or a loss on time. This
  checks that games complete; it measures nothing about strength. Details
  are in [TESTING.md](../TESTING.md).
- **Not checked:** a chess GUI and lichess-bot. The GUI check is the
  maintainer's. The tests and games above were run on Windows; what was run
  on the Linux build is not recorded in these notes.

## Getting it

Prebuilt binaries for x86-64 are attached to the GitHub release
`v0.1.0-alpha.1`, each with a `.sha256` file to check the download against:

- `vyvrael-0.1.0-alpha.1-windows-x86_64.exe`, built on the maintainer's
  Windows workstation from the tagged source. It is the build that passed
  the tests above.
- `vyvrael-0.1.0-alpha.1-linux-x86_64`, built on the maintainer's Linux
  machine. Its test results are not recorded here.

Both are plain release builds for any x86-64 processor, not tuned to one
machine. Binaries are never committed to the repository itself.

To build from source, with a stable Rust toolchain:

```sh
cargo build --release    # binary at target/release/vyvrael
```
